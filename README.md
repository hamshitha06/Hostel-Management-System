\# Hostel Management System



\## Project Overview



The Hostel Management System is a frontend web application

for managing common hostel activities.



\## Features



\- Student registration

\- Student login

\- Student dashboard

\- Room availability

\- Room booking

\- Payment management

\- Complaint management

\- Room vacating



\## Technologies



\- HTML
